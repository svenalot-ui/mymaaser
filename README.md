# Калькулятор маасера — mymaaser.online

Одностраничный калькулятор маасера кесафим: налоги, расходы на заработок, уже отданная цдака, 10% / 20% / своя ставка.
К каждому правилу указан источник и степень согласия поским.

- Один файл `index.html`, без сборки и внешних зависимостей (кроме шрифта Rubik с Google Fonts).
- Расчёт выполняется в браузере. Суммы нигде не хранятся и не отправляются; запоминаются только валюта, ставка и режим налогов.
- Публикуется через GitHub Pages, домен задан файлом `CNAME`.

## Важно

Калькулятор — справочный инструмент, а не галахическое решение. Тексты пояснений составлены как краткое изложение источников
и требуют сверки с раввином. В сложных случаях необходимо задать шаалат хахам.
